# Dacia Citymotors – Ohtuleht 1250x400

- **Run locally:** `yarn dlx serve .` or open via any static server (no build step).
- **Build:** none.
- **Upload:** `dacia_ol-1250x400.zip` (index.html at zip root).
- **ClickTag:** `https://b.ohtuleht.ee/scripts/ads.js` + `olBanner.getClickTag(url)`; background and each slide have own URL.
- **Env vars:** none. **Server:** HTTPS required for ads.js.
- **Open items:** Billboard limit is 100 KB; banner is ~145 KB.
